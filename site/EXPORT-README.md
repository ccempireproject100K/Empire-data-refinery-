# 20/20 Data Refinery — Final Free-Only Preview Export

The project remains Preview-only and uses only free public data sources. No paid provider credentials or premium data are included.

## Current capabilities

- 20 sector dossiers, claim-level evidence, source freshness, and exclusion history
- AI Skills Archive with 20 portable skills and safe connector metadata
- Free Public Data Catalog with 17 official datasets and 6 bounded live samples
- Read-only agent API for sectors, claims, sources, search, comparison, skills, metrics, companies, vintages, and comparability warnings
- Client-side ranking sensitivity controls that never overwrite published ranks or composites
- Update Engine review queue for source changes and unviewable links
- Downloadable JSON and Markdown research exports

Run locally with `npm start`, then open `http://localhost:3000`.

No API keys or secret values are included. Sources requiring free registration or API keys are documented but not called.
