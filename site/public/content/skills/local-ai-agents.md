# Local AI Agents

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Intermediate  
**Category:** Runtime choices

## Purpose

Assess local models and local agent runtimes for privacy, cost, latency, offline use, and hardware constraints.

## Use when

- Use when data should remain on a local machine.
- Use when experimenting without a hosted model endpoint.

## Capabilities

- Model selection
- Hardware fit
- Offline operation
- Local tool access
- Privacy review

## Workflow

1. Classify data sensitivity and connectivity requirements.
2. Measure local memory, throughput, latency, and quality constraints.
3. Select a model and runtime that fit the hardware.
4. Limit filesystem and network permissions.
5. Compare local quality and operating cost with hosted alternatives.
