# AI Risk Management Framework

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Intermediate  
**Category:** Quality and governance

## Purpose

Run AI risk as a continuous loop — Govern, Map, Measure, Manage — with named owners, a system inventory, and evidence for each decision.

## Use when

- Use when an organization needs one shared method for AI risk across teams.
- Use when agents move from experiments into systems people depend on.
- Use when customers or regulators ask how AI risk is managed.

## Capabilities

- Governance and ownership
- System inventory and context mapping
- Risk measurement plans
- Treatment and incident response
- Trustworthiness review

## Workflow

1. Govern: name accountable owners, set risk tolerance, and define approval gates.
2. Map: inventory each AI system with its purpose, data, users, and foreseeable misuse.
3. Measure: test performance, bias, robustness, security, and privacy against the mapped risks.
4. Manage: prioritize treatments, document accepted residual risk, and prepare incident response.
5. Apply the generative AI profile where models create content or act autonomously.
6. Repeat on a cadence and after every material change; the loop does not finish.
