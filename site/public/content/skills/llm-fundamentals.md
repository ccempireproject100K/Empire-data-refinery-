## Purpose

Explain tokens, embeddings, Transformers, generation limits, and practical model behavior to agent builders.

## Use when

- Use when choosing a model or explaining model limitations.
- Use when designing prompts, context windows, and evaluation examples.

## Capabilities

- Tokenization
- Embeddings
- Transformer concepts
- Generation behavior
- Model limitations

## Workflow

1. Define the task and the model capability it needs.
2. Estimate context, output, latency, and cost requirements.
3. Distinguish learned patterns from verified external facts.
4. Test representative inputs, edge cases, and refusal behavior.
5. Document model version and assumptions.
