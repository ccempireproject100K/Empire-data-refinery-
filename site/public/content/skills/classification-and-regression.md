# Classification and Regression

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Beginner  
**Category:** Machine learning

## Purpose

Choose supervised-learning targets, features, metrics, and thresholds for prediction tasks.

## Use when

- Use when an agent must score, classify, or predict from structured data.
- Use when comparing model errors and business trade-offs.

## Capabilities

- Target definition
- Feature preparation
- Threshold selection
- Confusion matrices
- Error analysis

## Workflow

1. Define the target and decision impact.
2. Split data without leakage and establish a baseline.
3. Select metrics that reflect the cost of false positives and negatives.
4. Inspect subgroup and slice performance.
5. Calibrate thresholds and monitor changes after deployment.
