# Production ML Systems

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Advanced  
**Category:** Operations

## Purpose

Move models and agent components from experiments into monitored, reproducible, maintainable production systems.

## Use when

- Use when an AI prototype must run reliably for users.
- Use when planning data, model, infrastructure, and rollback responsibilities.

## Capabilities

- Data pipelines
- Versioning
- Deployment
- Monitoring
- Rollback design

## Workflow

1. Define service-level objectives and ownership.
2. Version data, code, prompts, models, and evaluation sets.
3. Automate tests and reproducible builds.
4. Monitor quality, latency, cost, drift, safety, and dependency health.
5. Prepare rollback, incident response, and retraining triggers.
