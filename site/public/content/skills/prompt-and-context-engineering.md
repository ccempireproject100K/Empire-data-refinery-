# Prompt and Context Engineering

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Beginner  
**Category:** Foundations

## Purpose

Shape instructions, context, examples, and constraints so an agent produces reliable, bounded work.

## Use when

- Use when an agent is vague, inconsistent, or overconfident.
- Use when designing system instructions and reusable task templates.

## Capabilities

- Instruction hierarchy
- Context selection
- Few-shot examples
- Output schemas
- Constraint design

## Workflow

1. State the task, audience, output, and success criteria.
2. Provide only relevant context and define source priority.
3. Give examples for ambiguous formats or edge cases.
4. Require structured outputs when downstream software will consume results.
5. Test adversarial, incomplete, and out-of-scope requests.
