# Generative Media Generation

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Beginner  
**Category:** Generative media

## Purpose

Create and edit images with generative models inside an application while handling prompts, safety, and asset provenance deliberately.

## Use when

- Use when an app needs illustrations, mockups, or visual variants.
- Use when editing or extending existing images with a model.
- Use when generating media at a scale manual design cannot cover.

## Capabilities

- Visual prompt design
- Image editing workflows
- Style consistency
- Safety and rights checks
- Asset cataloging

## Workflow

1. Define the asset: subject, style, dimensions, and where it will be used.
2. Write prompts that specify composition and exclusions, not just subject keywords.
3. Generate variants and select against the brief rather than the first output.
4. Check outputs for artifacts, text errors, likeness, and rights problems.
5. Store the prompt, model, and generation settings with the final asset for reproducibility.
6. Label AI-generated assets where users or regulators expect disclosure.
