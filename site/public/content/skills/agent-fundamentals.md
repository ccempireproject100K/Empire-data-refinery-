# Agent Fundamentals

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Beginner  
**Category:** Foundations

## Purpose

Plan, build, and evaluate an AI agent using tools, observations, actions, and clear task boundaries.

## Use when

- Use when designing a new agent workflow.
- Use when deciding whether a task needs an agent, a deterministic script, or a simple prompt.
- Use when documenting an agent so another system can reproduce it.

## Capabilities

- Agent loop design
- Tool selection
- Task decomposition
- Failure handling
- Evaluation planning

## Workflow

1. Define the user goal and success criteria.
2. Separate deterministic work from judgment and tool use.
3. Describe the agent loop: plan, act, observe, verify, and report.
4. Set permissions and failure boundaries before connecting tools.
5. Test with representative examples and record uncertainty.
