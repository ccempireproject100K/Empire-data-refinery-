# ML Evaluation and Fairness

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Intermediate  
**Category:** Quality and governance

## Purpose

Measure model quality, generalization, production behavior, and fairness before relying on an AI system.

## Use when

- Use when selecting metrics for a model or agent.
- Use when monitoring drift and production quality.
- Use when reviewing bias, subgroup performance, and responsible deployment risks.

## Capabilities

- Metric selection
- Train/test discipline
- Error analysis
- Fairness review
- Production monitoring

## Workflow

1. Define the decision, population, and acceptable error trade-offs.
2. Create a representative evaluation set and keep it separate from tuning data.
3. Report precision, recall, calibration, latency, cost, and subgroup performance where relevant.
4. Test robustness, distribution shift, safety, and human escalation paths.
5. Document limitations and establish a review cadence.
