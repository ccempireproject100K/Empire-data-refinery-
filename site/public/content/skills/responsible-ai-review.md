# Responsible AI Review

> Derived archive skill. This file summarizes public sources and does not reproduce source-course text.

**Level:** Intermediate  
**Category:** Quality and governance

## Purpose

Review an AI system for fairness, transparency, privacy, safety, accountability, and human oversight.

## Use when

- Use before launching a user-facing AI feature.
- Use when a model affects eligibility, ranking, safety, or access to services.

## Capabilities

- Impact assessment
- Fairness review
- Human oversight
- Transparency notes
- Risk register

## Workflow

1. Define affected people, decisions, and potential harms.
2. Measure performance across relevant groups and conditions.
3. Document data provenance, limitations, and intended use.
4. Provide appeal, correction, and human-escalation paths.
5. Review incidents and update controls as the system changes.
